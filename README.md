# Navigator 3 — Issue Tracker

**Navigator 3** is a wireless gamma probe system for intraoperative sentinel lymph node identification, developed by [Dilon Technologies](https://www.dilon.com).

This repository is the official issue tracker for the Navigator 3 product. All issues are reviewed by the Nav3 development team.

## Filing an Issue

Click **New Issue** and select the appropriate template. A GitHub account is required.

| Type | Use when |
|---|---|
| **Bug / Defect** | Something is not working correctly |
| **Feature Request** | You would like a new capability or improvement |
| **Documentation Issue** | A problem with labeling, IFU, or on-screen text |
| **General Feedback** | Usability observations or open-ended suggestions |

## What to Include

- Which Navigator 3 component is affected (probe, tablet app, display unit, etc.)
- Software version — visible in the tablet app under **Settings → About**
- Steps to reproduce the issue
- Expected vs. actual behavior

## Contact

For urgent issues or questions not suited for this tracker, contact the Nav3 development team at **bchaloux@dilon.com**.
